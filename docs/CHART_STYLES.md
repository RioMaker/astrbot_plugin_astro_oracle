# 星图外围版式候选

2026-10-10 按用户要求搜集视觉参考并制作三种候选。用户已确认优化后的 B 版，并授权本地提交；AstrBot 默认图片采用空间观测台风格与紧凑天体信息表，已有双半球星盘继续复用。A/C 保留为本地预览方案。

## 参考与设计取向

下表的配色、排版和装饰是本插件的设计归纳；参考作品用于确定视觉方向。

| 候选 | 参考 | 本次版式 |
| --- | --- | --- |
| A · 纸本典藏 | [David Rumsey 收藏的 Samuel Dunn 1787 年图册](https://www.davidrumsey.com/maps2600.html)，包含天球南北半球及太阳系等附图 | 暖米色纸面、细双线框、居中标题、铜棕点缀；行星采用图录式分栏 |
| B · 空间观测台 | [NASA Hubble Skymap](https://science.nasa.gov/mission/hubble/multimedia/online-activities/hubble-skymap/) 的天文交互图方向 | 深色背景、青绿与蓝紫标识、四角仪表边框、分级时间信息和紧凑天体信息表 |
| C · 极简画廊 | [Baltic Club Sky Map Art Print](https://www.thebalticclub.com/products/sky-map-art-print) 的双圆星图海报与简洁字体方向 | 暖白留白、大标题、砖红几何装饰；七个行星用简洁的两行信息表 |

## 保留内容

三版都使用北京 `2026-10-10 20:30:00 Asia/Shanghai` 的同一真实计算结果。恒星位置/亮度、行星、太阳方位、星座连线、名称筛选和投影保持一致；只修改星盘外侧的方位刻度与文字配色，并重排标题、时间地点、行星摘要和来源说明。暖色或浅色背景不代表天空的实际亮度，标题装饰不表示天体。

渲染实现位于 `local_core/image_styles.py`，由 `tools/preview_chart_styles.py` 独立预览。所有字体沿用随附字体；不增加网络渲染、运行依赖或 AstrBot 配置项。A/C PNG 尺寸为 `1760 × 1510`，新版 B 为 `1760 × 1650`，对照图按原比例缩放。

## B 的底部优化

去除七张大行星卡，改为与星盘对应的上下半球两组，每组两列紧凑信息表。先列出本侧行星，再列出当前星等筛选结果中最亮的 12 颗恒星；不足 12 颗时按实际数量展示。不以通用名称是否存在筛掉恒星，无名称时展示“未命名”及真实 HIP 编号。关闭恒星名称时展示“恒星”及 HIP 编号。

每行保留名称、恒星 HIP 编号、视星等、高度和方位角；行星的 HIP 列显示“—”，不赋予恒星编号。方位北为 0°、东为 90°，高度正/负对应地平线以上/以下。未知模型星等显示“未知”。表中补充的信息不改变星盘内的名称密度或真实星点。北京预览共包含 7 个行星及 24 颗亮星。

## 复现与验收

在插件目录使用已安装依赖的 Python 执行：

```powershell
.venv/Scripts/python.exe -m tools.preview_chart_styles
```

本地预览位于被忽略的 `data/style-preview/`：`archive.png`、`observatory.png`、`gallery.png`，另有 `comparison.png` 对照图和 `original.png` 原版。脚本比较每版与原版半径 322 像素内的星盘像素，确认恒星、连线与标注未改变；圆盘半径为 324 像素，留出边界抗锯齿与方位外圈。

三种完整图片已逐张视觉检查，保留标题、时间地点、方向、天体摘要与作者/许可信息。确认后的 B 版通过 `ChartService` 接入 `/星图` 系列；`tools/preview_bot_chart.py` 使用同一服务生成实际输出，预览与指令不使用不同的排版实现。
