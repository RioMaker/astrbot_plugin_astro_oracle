# 紫微星名真实天球预览

2026-10-12 的本地测试原型，目录版本 `ziwei-real-sky-preview-v2`。沿用 `/星图` 的时间、地点、默认值与四个前缀，在独立脚本中生成单盘明暗新图。尚未接入 `main.py`、`ChartService`、网页或 AstrBot 消息发送；普通星图仍按原有方式生成。图片与查询审计只由显式本地预览脚本保存在被忽略的 `data/ziwei-validation/`。

- 天魁、天钺、天马、八座、其他杂曜与四化没有本次采用的可靠单目标，不以太阳系行星或附近恒星凑数。

## 真实计算与显示

计算复用已校验的 DE440s、Hipparcos、GeoNames。恒星使用普通星图原有的站心视方向、自行与视差传播；日月使用同一 UTC 时刻及 WGS84 观测点，NAIF 10/301，计算光行时、光行差与引力偏折。天顶/天底投影、东西方向及无折射地平线定义见[星图说明](SKY_CHART.md)。这次未另外认证月球全天文精度。

仅绘目录内对象，去掉背景恒星与其他行星。普通星图的星等上限和名称开关不隐藏这个目录的选定对象。对象或真实坐标缺失会明确失败，不输出虚构坐标。JSON 仍保留双半球分组及裁剪连线供核对，单盘图暂不绘星官连线。

十四主星使用金色强调环和大字；禄存、文曲、左辅使用青色环和小字。恒星中心点保持原 V 星等曝光映射，分类强调环不代表星体角直径或亮度。日月星等未计算，采用空心定位符号；月球符号不声称模拟当日月相。所有名称进行避让，并输出标签框供本地检查。

单盘以天顶为中心、方位北上东左，半径为 `(90°−高度)/180°`。高度 0° 对应半径一半；地平线以上位于内圆，用明亮文字，以下位于外圈，用暗淡文字。**明暗是地平线上下的显示状态，不是斗数庙旺落陷，也不保证肉眼可见。** 天底为外缘的投影极限，面积不代表两半球大小，不用该平面距离测量真实角距。

六煞的天体候选和两组古籍宫界表已经查阅并记录在[文献核对](ZIWEI_LITERATURE.md)。尚待用户确认采用候选星官还是斗数安星符号，图中只列待考名称，没有给六煞或宫界填入未确认的坐标。

## 复现

在插件根目录使用自己的 `.venv`：

```powershell
.\.venv\Scripts\python.exe -m tools.preview_ziwei_chart --input '/星图 北京 20261012200000'
.\.venv\Scripts\python.exe -m tools.preview_ziwei_chart --input '/xt 北京 200010100100' --output data/ziwei-validation/beijing-2000.png
.\.venv\Scripts\python.exe -m tools.preview_ziwei_chart --input '/star -33.8688,151.2093 20261012120000' --output data/ziwei-validation/southern.png
```

脚本同时保存 PNG 与同名 JSON。JSON 保留最终 UTC/当地时间、补齐说明、地点来源、实际高度/方位/投影坐标、星等、HIP/NAIF、对应性质、映射版本、源与算法校验值、标签位置及图片 SHA-256。只有显式预览会写这些合成测试输入，AstrBot 仍不自动保存用户查询。

后续若确认这张图接入，继续使用相同 `/星图` 参数，并在原图之外增加返回新图；本阶段只供本地看图，版本仍为 `0.1.4`。
