# 传统安星规则与真实天体对照

查阅和计算：2026-10-12。研究版本 `quanshu-core-comparison-v1`。仅新增独立研究脚本与结果；现有方位盘、宫卡、时间解析、注册指令、版本和上线状态不变。

## 规则基线

参考[《紫微斗数全书》卷二的固定网络录文](https://zh.wikisource.org/w/index.php?oldid=1963110)，并用 [iztro 作者的安星说明](https://docs.iztro.com/learn/setup)及其 2.6.1 SDK 交叉核对。录文不是经过本轮古刻扫描校勘的定本，也不能代表所有流派的唯一标准。

学习与对照的是静态安星核心：农历年、月、日和时辰 → 命身及十二事项宫 → 五虎遁排宫干 → 命宫干支纳音定水二、木三、金四、土五、火六局 → 生日与局数安紫微 → 紫微六曜逆布、天府八曜顺布。辅煞另外依年、月或时安置，四化依年干附着于星曜；庙旺表与实际高度、V 视星等是不同量。

计算范围为十四主星、禄存、文昌、文曲、左辅、右弼及六煞，共 25 个静态位置；四化按本次固定录文保存。未实现全书全部杂曜、长生十二神、运限、流盘或命运解释，也未将任意星官、交点或行星强配到杂曜。

本轮没有在这些安星步骤中找到必须查询真实赤经、赤纬或行星历表的操作。把地支落宫与真实天区并排比较，需要另外采用现有[星名映射和古界研究层](ZIWEI_SKY_PREVIEW.md)；该对应不由安星口诀自动证明。

## 需要冻结的版本选择

- 闰月：固定《全书》录文将闰月按次月安命身；当前预览按前十五日原月、后十五日次月。研究脚本提供 `quanshu_next` 与 `preview_split` 两版，不修改原预览。2020-05-23 子时（闰四月初一），两版分别命宫午、巳。闰十二月的跨年解释未定，不自动推断。
- 时间：此次继续用当地民用日期套中国农历、23 点换次日，不做真太阳时。不是本轮证明的全书唯一换日标准。
- 火铃：全书此段给年支起位；生时顺数采用现代安星说明补全，已和独立 SDK 对照，来源分别标明。
- 四化：本次录文壬干化科为天府，iztro 文档的南派表为左辅。本例为丙年，没有该分歧；本研究不混表。庙旺与星等分列，也不自动把庙旺转换成亮度。
- 转录疑点：录文木三局图在寅、辰均列初九，缺初五；通行算法与 SDK 为初五寅、初九辰。另有魁钺“丙丁猪狗”与现代说明亥酉的异字。未查原刻扫描前记录疑点，不按录文字面改现有插件规则。

## 独立验证与复现

《全书》卷二固定录文 revision `1963110`，原始 wikitext SHA-256 `1e255c6ae99e6f89ae124ab342554ef1347fc8e68fb8908cba7290d1a38cbb72`。网络材料只保存在被忽略的 `data/ziwei-validation/rule-sources/`。现代源码参考固定于 iztro commit `540b12b7b6cf17fa263dbff724b639552b43691c`；实际运行核验使用 npm **2.6.1**，不声称这两个快照完全相同。

SDK 安装仅在忽略目录，关闭安装脚本；未加入运行依赖或改动 AstrBot。独立结果快照为 `tests/fixtures/ziwei_iztro_2_6_1.json`，记录 npm 完整性值和实际编译模块哈希。`getStartIndex` 分别用丙子、戊辰、甲子、庚子、丙寅强制二至六局，对 2026 年正月的 30 个生日检查全部 150 个紫微位置。另核对 2026-10-12 戌时、次日戌时、2000-10-10 子时的 25 个已实现静态星位；命宫纳音与既有农历库独立表交叉核对。SDK 只作现代实现参照，不代替古籍版本校勘。

在插件根目录，用原开发环境运行：

```powershell
.\.venv\Scripts\python.exe -m tools.compare_ziwei_rules
```

显式脚本输出 JSON 与 PNG，保留传统推演、真实目标/HIP/NAIF、赤经赤纬、高度方位、研究天区、历法约定、来源及代码和图片哈希。JSON 中七颗行星另外列出，六煞无实体坐标。生日次日紫微从辰变丑，而现代北极星仍在本研究戌区；同一时辰内传统星位不变，真实地平坐标连续变化。现有方位盘不被这份研究结果替换。
