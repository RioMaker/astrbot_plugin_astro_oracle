# 紫微命盘与真实天体的对应方式 V2

查阅与方案日期：2026-10-13，按本次用户客户端日期记录。本轮改用传统地支落宫与现代站心方向分列的方式，真实侧采用天顶全天投影、星点旁双名和共有编号。本文固定展示语义与证据边界；实际预览、指令回归及验证结果由本轮实现记录补充。

## 两侧分别表示什么

传统侧沿用[《全书》静态安星核心](ZIWEI_RULE_COMPARISON.md)：从输入时刻取得农历年、月、日和时辰，安命身、宫干与五行局，再安十四主星、已实现的辅煞和四化。地支与事项宫是这套安星规则的输出。闰月、换日、火铃及四化仍采用明确记录的研究版本，不因换投影或视觉样式暗中改表。查询时刻在此作为排盘输入；图本身不额外采集个人出生资料。

真实侧表示同一 UTC 时刻、同一观测地点的天体方向：恒星沿用 Hipparcos 标识与现有位置传播，日月沿用 JPL 实体和站心视方向。高度、方位角属于现代天文计算结果，天体点位置不因传统落宫或文字避让而移动。

两侧共用编号和传统名称，表达“本图选用这个天体来展示这个名称”。对照表直接列传统落宫、现代目标、高度与方位、对应依据。它没有把传统宫位变换成一个物理角度，也没有把天体所在方向重新命名为命宫、财帛宫等事项宫。

| 对照信息 | 传统侧 | 真实侧 |
| --- | --- | --- |
| 输入 | 同一个规范化时刻，按记录的当地历法规则取年、月、日、时 | 同一时刻转换后的 UTC、WGS84 观测点 |
| 位置 | 地支格与事项宫，例如“寅·福德” | 站心高度与方位角，例如“高度 …°、方位 …°” |
| 名称 | 斗数星曜名及共有编号 | 同编号、斗数名称及选定现代天体简称 |
| 无实体对应的符号 | 按传统规则落宫 | 没有虚构天体点、高度、方位或星等 |

## 为什么不采用直接的宫位空间变换

[《紫微斗数全书》卷二的网络录文](https://zh.wikisource.org/zh-hant/紫微斗數全書/卷二)给出的安身命、纳音定局与南北斗安星步骤，以历法与格位顺逆为操作对象。本次核对的静态安星核心没有要求查询实体星的赤经、赤纬或行星历表。因此，从这些步骤本身不能推导出“某事项宫就是观测者某个方位范围”，也不能用实体星的坐标替换传统安星结果。这是对已核对步骤的推论，不是对所有古籍天文内容的否定。

十二次是古代描述天体位置的天区系统，斗数十二事项宫则是按命宫起排的事项名称；共用十二辰标签不构成二者空间边界相同的证明。[日本国立天文台历计算室“十二次”](https://eco.mtk.nao.ac.jp/koyomi/wiki/BDBDC6F3BCA1.html)说明了宿度、节气与十二次的关系，以及岁差带来的变化和古籍改订值。恢复现代绝对边界仍需核对古历元、宿距星、坐标基准、古度制与起算方式，不能只把古度乘以单位比例后锚定当前恒星。

上一版使用的 `jinshu-current-anchor-equatorial-v1` 已在[古界研究说明](ZIWEI_LITERATURE.md)中记录为今星锚定示意，未完成十二个现代绝对边界的复原验收。本版不把该边界带入主图，也不以它给天体分配“真实事项宫”。

北斗七星的逐星别名见[《太上玄灵北斗解厄本命延生真经》网络录文](https://zh.wikisource.org/zh-hant/太上玄靈北斗解厄本命延生真經)和[香港太空馆“中国星空神话”的北斗条](https://hk.space.museum/sc/web/spm/resources/teachers-corner/constellations-and-myths/chinese-starlore.html)。前者逐一列出七星宫名与星君名号，后者同时说明现代常用的北斗星名。录文中的“天衡”“闓阳”等字形与现代标签作对应说明，不将字形差异解释成换了一颗天体。网上录文是原始文献的转录来源，本轮没有把它声称为完成古刻扫描校勘的定本。

香港太空馆也说明“辅”为开阳伴星。该星官识别可以支持本图展示 Alcor，但还不能独立证明斗数左辅的唯一对应。南斗各名称与当前六个 HIP 的桥接继续保留展示约定性质，完整目录沿用[原预览说明](ZIWEI_SKY_PREVIEW.md)，本次不为了提高“同格”数量而更换目标或星序。

Polaris 是当前接近北天极的恒星；[NASA 的北极星说明](https://science.nasa.gov/solar-system/what-is-the-north-star-and-how-do-you-find-it/)指出北极星会随岁差更替。因此“紫微—Polaris”明确作为当代展示选择，不能从当前北极星反证历史帝星一直是同一颗恒星。

斗数火星继续作为传统安星符号；本图不因中文同名把它放在 Mars 坐标。未映射是本图没有采用已确认的单目标，不是“这些名称不存在任何天文史线索”。

## 真实图的方向与状态

本版使用现有 `single_xy` 的站心全天等距方位投影。设实际高度为 `h`、方位角为 `A`，完整图盘半径归一化为 1：

```text
r = (90° - h) / 180°
x = -r × sin(A)
y = -r × cos(A)
```

天顶 `h = +90°` 在圆心，理想地平线 `h = 0°` 在半径 0.5 处，地平线下方向位于外圈，天底 `h = -90°` 是投影外缘的极限。北在上、东在左、南在下、西在右，按仰视星空的约定标出；方位角数值仍自北起顺时针，东为 90°。该平面图不能用任意两点的直线距离直接测量球面角距，图上面积也不是天空面积。

[Skyfield 官方坐标说明](https://rhodesmill.org/skyfield/coordinates.html#altitude-and-azimuth-horizonal-coordinates)给出站心地平坐标的定义。星点旁的名称由避让布局移动，实体点保留原始 `single_xy`；共有编号与短引线只负责读图，不改变实体方向。天体名称、坐标标识和所选映射性质应一并保留在本地结果的溯源信息中。

本图高度沿用无大气折射的计算。根据[Skyfield 官方位置说明](https://rhodesmill.org/skyfield/positions.html#adjusting-altitude-for-atmospheric-refraction)，普通 `altaz()` 返回没有大气时的理想高度；加入折射也只是依气象条件估计。本图显示“地平线上方／下方”，不把前者写成“肉眼可见”。日光、天气、地形、遮挡与背景亮度并未通过一个正高度值得到验证。恒星 V 星等、日月模型星等与斗数庙旺也分别表示不同的量，不能互相换算。

## 与上一版对照图的区别

上一版主图以北天极为中心，叠加研究宫界，并用研究地支归属与传统地支格比较“同／异”。这一结果依赖名称映射和古界模型，不能作为排盘正确率或角误差。

本版真实图围绕观测地点的天顶展开，地平线直接呈圆环，名称显示在实体星点附近。传统宫位仍在传统侧及说明表中明确给出。对应由同名、双名和共有编号表达；主图取消古界扇区、真实事项宫标题与同异统计，避免把尚未认证的空间假设变成默认归属。

本次入口定为 `/紫微星图`；旧 `/星图`、`/xingtu`、`/xt`、`/star` 的普通星图输出保持原有职责。两种图可共用时间地点解析与公共天文资源，图形入口和输出语义分别管理。具体接入与本地回归结果以本轮实现记录为准；本文不预填上线或平台验收结论。
