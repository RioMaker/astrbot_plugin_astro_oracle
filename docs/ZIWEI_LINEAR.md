# Linear 紫微星图本地预览

本文记录上一版无关联区域的对照图，原预览脚本继续保留。当前 `/紫薇星图` 与 `/紫微星图` 的指令输出已切换为 [天球与命盘图](ZIWEI_ATLAS.md)。

本轮按附件 Linear 风格重构紫微对照图。背景 `#0a0a0b`、白色主文字、`#a1a1aa` 次文字和低权重细线；靛色 `#5e6ad2` 只用于命身格的边界。取消装饰光晕、纹理与衬线。英文、数字和符号来自随附 Inter 派生字体，汉字由随附 AstroSans 补全；来源与 OFL 许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

## 读图

- 左侧按传统地支格显示事项宫、25 个静态星曜及四化；星名留在其传统落宫中，命身有边界提示。
- 右侧是观测地点的全天方向，天顶在中心，北上东左。半径一半的圆环是 0° 地平线：实心点表示上方，空心点表示下方。外圈不是第二个物理球体。
- 17 个共有名称直接放在星点附近，第二行给出现代目标简称。短引线、名称与固定编号连接两侧；文字避让不移动实体星点。
- 底表逐项列出传统宫位、V 星等、实际高度和方位。`*` 表示展示约定，`[符]` 表示未采用单体映射，日月星等的 `~` 表示模型估计。

传统排盘不由真实天体的高度、方位决定；新版主图不采用尚未认证的古宫界，也不输出“真实事项宫”或同异正确率。来源与对应等级详见 [对应方式 V2](ZIWEI_CORRESPONDENCE_V2.md)。正高度不等于肉眼可见，庙旺也不等于实测光度。

## 指令与范围

只注册 `/紫微星图`，不添加别名，不匹配旧 `/星图`、`/xingtu`、`/xt`、`/star`。参数解析与公共资源复用原服务；默认地点、补齐时间、时区和 `enabled` 总开关共用，普通星图的名称、连线和星等显示开关不隐藏紫微固定对象。

传统核心采用已记录的《全书》研究版本，包括宫干、五行局、十四主星及当前辅煞、四化表；闰月默认整月作下月，晚子跨日按现有记录处理。本轮没有调整这些规则或添加运限。支持历法范围为 1900–2100 年；同一时间地点与输入补齐说明保留在图片及显式预览 JSON 中。

`lunar-python==1.4.8` 由开发依赖移入运行依赖。新入口使用普通异步协程，在首次等待前固定请求时间、配置和会话；与普通星图复用一个计算线程及资源引擎。群内生成只返回内存 PNG，不自动保存用户查询或图片。

## 显式本地预览

```powershell
python -m tools.preview_ziwei_linear --input '/紫微星图 北京 20261012200000'
```

默认保存到被 Git 忽略的 `data/ziwei-validation/linear/beijing.png`，尺寸 `2440 × 1810`。同名 JSON 保存真实数据、传统规则、对应等级、标签边界、原始星点坐标、数据来源及图片／代码／字体校验值。只有这个显式脚本保存预览文件。

本轮交付仅本地预览和回归验证；真实 AstrBot 加载、OneBot／QQ 传输及运行端依赖安装另行联合验收。检查结果见 [验证记录](VALIDATION.md)。
